# Getting Started

Checkout this repository:
```bash
git clone https://github.com/dsunshi/haskell-flake-template.git <my-project>
cd <my-project>
```

Setup Cabal:
```bash
cabal init
```
or
```bash
cabal init --non-interactive
```

## Optional

Allow direnv:
```bash
direnv allow

Download local hoogle index:
```bash
hoogle generate --download
```
